# Proyek Website Sinergi Solusi Digital

Proyek ini merupakan implementasi website profil perusahaan "Sinergi Solusi Digital", dengan fokus pada penerapan HTML, CSS, dan JavaScript, termasuk validasi formulir dan responsivitas.

## Fitur Utama

* **Halaman Beranda (Home):** Menyambut pengunjung dan menampilkan informasi dasar perusahaan serta lokasi kantor pusat.
* **Halaman Profil Perusahaan (Our Profile):** Detail tentang perusahaan, visi, misi, dan tim kepemimpinan.
* **Formulir "Hubungi Kami" (Message Us):** Formulir kontak interaktif dengan validasi input menggunakan JavaScript.
* **Desain Responsif:** Tampilan website menyesuaikan dengan berbagai ukuran layar (desktop, tablet, mobile).
* **Navigasi Interaktif:** Navigasi antar halaman yang jelas.
* **Integrasi Google Maps:** Lokasi kantor pusat terhubung langsung ke Google Maps.

## Cara Menjalankan Proyek

1.  **Clone repositori:**
    ```bash
    git clone <URL_REPOSITORI>
    ```
2.  **Masuk ke direktori proyek:**
    ```bash
    cd <nama-folder-proyek>
    ```
3.  **Buka file `index.html`** di browser web.
